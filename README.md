# Jazmín · Mis 15 años

Invitación digital estática para GitHub Pages.

## Publicar
1. Crear un repositorio nuevo en GitHub.
2. Subir **todo el contenido** de esta carpeta (index.html, styles.css, script.js y assets), no el ZIP sin extraer.
3. Ir a **Settings → Pages → Build and deployment**, seleccionar **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guardar.
4. Abrir la URL publicada de GitHub Pages.

## Funcionamiento
- El sello y el botón de la portada abren la invitación sin recargar, permitiendo iniciar el audio por el gesto del visitante.
- La cuenta regresiva utiliza horario de Argentina (UTC-3).
- Las zonas transparentes sobre los botones de las imágenes son enlaces reales.
- La música se puede pausar o reanudar con el botón flotante. Si alguien abre directamente el enlace con `#invitacion`, puede necesitar pulsar música manualmente por restricciones del navegador.

## IMPORTANTE: formulario de mensajes
El enlace proporcionado termina en `/edit`, que puede abrir el editor o pedir permisos, en lugar del formulario para invitados. Reemplazarlo en `index.html` por el enlace público de **Enviar → enlace** del Google Form antes de compartir la invitación.
